# login-terminal

Siber güvenlik temalı (sözde hacker terminali) giriş sayfası. Saf HTML, CSS ve JavaScript.

## Çalıştırma

`index.html` dosyasını tarayıcıda aç. Kurulum gerekmez.

## Demo giriş

- Kullanıcı: `root`
- Şifre: `mustio2026`

3 yanlış denemede ekran 10 saniye kilitlenir.

## Not

Bu proje sadece ön yüz tasarımıdır. Şifre kodun içinde durduğu için gerçek bir güvenlik sağlamaz. Gerçek giriş için bir sunucu veya Firebase / Supabase gibi bir servis gerekir.

## Dosyalar

- `index.html`: sayfa yapısı
- `style.css`: tasarım
- `script.js`: giriş mantığı ve animasyonlar
